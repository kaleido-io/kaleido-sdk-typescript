# Templates

Each subdirectory is a self-contained, runnable project that demonstrates a
different use case of the Kaleido Workflow Engine SDK.

To get started with a sample, fork or copy the directory and follow the README
inside it. Alternatively, you can create a new project from scratch using `npx @kaleido-io/workflow-engine-sdk init <project-name> --template <template-name>`

| Sample | Description |
|--------|-------------|
| [getting-started](./getting-started/) | A set of examples that show the broad set of capabilities of the SDK and the Kaleido workflow engine |
| [erc20-indexer](./erc20-indexer/) | Indexes ERC-20 `Transfer` events into the Kaleido Asset Manager |
